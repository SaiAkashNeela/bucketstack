What BucketStack does

BucketStack is a free, open-source desktop app for macOS, Windows and Linux. It works with AWS S3, Cloudflare R2, MinIO, Wasabi, Backblaze B2, DigitalOcean Spaces, Railway and any other S3-compatible service.

  • Edit JSON, YAML, Markdown, CSV and code files directly in your bucket.
  • Copy files between storage providers with live progress.
  • Restore deleted files from Trash, and share download links that expire.
  • Back up a folder on a schedule, review the activity history, zip files and see storage breakdowns.
  • Access keys stay on your computer, encrypted with AES-256-GCM. No account and no tracking.
