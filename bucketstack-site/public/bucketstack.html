A native S3 client.
Not another Electron tab.

BucketStack is a Rust-built desktop app for browsing, syncing and editing files across AWS S3, Cloudflare R2, MinIO, Wasabi and any other S3-compatible endpoint. No web wrapper. No account required.

zero servers to breach

Your keys never leave your machine — because we don't run one.

There's no BucketStack backend for your credentials to pass through. The app talks straight to your provider.

  • AES‑256‑GCM at rest. Credentials are encrypted and bound to your machine's identifier.
  • Direct connection. Requests go straight to your provider's API — no proxy in between.
  • OS-level sandboxing. Tauri's permission model keeps the app scoped to what it needs.
const credentials = await secureStorage.get("aws_access_key");
// pulled from the OS-encrypted store, on this machine only

const s3 = new S3Client({
  region: "us-east-1",
  credentials,
});
// request goes directly to AWS — no BucketStack server in the path
